# vulkan

* [vulkan-tutorial.com](https://vulkan-tutorial.com/)
  * The de facto starting point for learning Vulkan from scratch.
    Walks through setting up a complete rendering pipeline step by step — from instance creation to drawing your first triangle.

* [vkguide.dev](https://vkguide.dev/)
  * Alternative hands-on tutorial with a more modern approach — uses dynamic rendering and VulkanMemoryAllocator from the start. Good second read after vulkan-tutorial.com.

* [Vulkan in 30 minutes](https://renderdoc.org/vulkan-in-30-minutes.html) — by the author of RenderDoc
  * Dense but brilliant overview of the whole API. Great for getting the big picture before (or after) the full tutorial.

* [KhronosGroup/Vulkan-Guide](https://github.com/KhronosGroup/Vulkan-Guide)
  * Official supplemental guide covering synchronization, memory types, render passes, and common pitfalls. Not a tutorial — more of a reference.

* [Vulkan Spec](https://registry.khronos.org/vulkan/specs/latest/html/)
  * The authoritative source. Intimidating at first, but invaluable once you know the basics.
